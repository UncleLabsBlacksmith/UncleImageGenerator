# Uncle Image Generator

โปรแกรมสร้างและแก้ไขรูปภาพด้วยโมเดล AI ผ่าน [OpenRouter](https://openrouter.ai/) API เขียนด้วย Python + Tkinter ไฟล์เดียว

- สร้างรูปจาก prompt ภาษาไทยหรืออังกฤษ
- ให้โมเดลช่วยแปลหรือขยาย prompt เป็นภาษาอังกฤษ
- เลือกรูป reference (เช่น โลโก้) ให้ AI นำไปใส่ในภาพที่สร้าง
- ประวัติรูปพร้อม prompt และต้นทุนของแต่ละครั้ง นำ prompt หรือการตั้งค่าเดิมกลับมาใช้ได้
- ดูรายการโมเดลสร้างรูปพร้อมราคา เรียงตามชื่อ ถูกสุด หรือแพงสุดได้
- ยกเลิกการสร้างรูประหว่างรอผลได้

## ความต้องการของระบบ

- Windows 10 หรือ Windows 11 (โค้ดรองรับ macOS/Linux ในระดับพื้นฐาน แต่ทดสอบเฉพาะ Windows)
- Python 3.10 ขึ้นไป (ทดสอบกับ Python 3.14)
- บัญชี OpenRouter พร้อม API Key และเครดิต (สร้าง key ได้ที่ https://openrouter.ai/keys)

## การติดตั้งและรันจากซอร์ส

```bash
pip install pillow
```

```bash
python uncle_image_generator.py
```

ไลบรารีภายนอกมีตัวเดียวคือ `pillow` ใช้แสดงและย่อรูป JPG/WebP ส่วนการเรียก API ใช้ `urllib` ของ Python เอง

## วิธีใช้งาน

1. ครั้งแรกโปรแกรมจะเปิดหน้าต่าง **ตั้งค่า API Key** ให้วาง key แล้วกด **ทดสอบ Key** และ **บันทึก**
   (หรือกำหนดตัวแปรสภาพแวดล้อม `OPENROUTER_API_KEY` แทนก็ได้)
2. โปรแกรมจะโหลดรายการโมเดลจาก OpenRouter อัตโนมัติ กด **F5** เพื่อโหลดใหม่
3. ที่แท็บ **สร้างรูป**
   - เลือกโมเดลสร้างรูป และโมเดลช่วยคิด prompt (ใช้เมื่อเลือกโหมดช่วยคิด)
   - เลือกโหมด prompt: ไม่ช่วยคิด / แปลเป็นอังกฤษ / แปลและขยายเป็นอังกฤษ
   - เลือกอัตราส่วนภาพ (ไม่ระบุ, 1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3)
   - เพิ่มรูป reference (png, jpg, webp, gif ไม่เกิน 20 MB ต่อไฟล์) แล้วเขียน prompt ระบุตำแหน่งที่ต้องการ
   - กด **สร้างรูป** หรือ `Ctrl+Enter` ระหว่างรอ ปุ่มจะเปลี่ยนเป็น **ยกเลิก**
4. ผลลัพธ์แสดงทางขวา พร้อมต้นทุนของการสร้างครั้งนั้น และ prompt อังกฤษที่ส่งจริง
5. แท็บ **ประวัติ**: ค้นหาได้ เลือกรายการเพื่อดูรายละเอียด แล้วกลับไปใช้ prompt เดิม (ไทย หรืออังกฤษ) หรือโหลดทั้งหมด (รวม reference และโมเดล) ได้
6. แท็บ **โมเดลและราคา**: สลับดูโมเดลสร้างรูปหรือโมเดลข้อความ เรียงตามชื่อ ถูกสุด หรือแพงสุด แล้วตั้งเป็นโมเดลที่ใช้งานได้ทันที

### ต้นทุน

- ต้นทุนจริงของแต่ละครั้งมาจากฟิลด์ `usage.cost` ที่ OpenRouter ส่งกลับ
- ถ้า API ไม่ส่งค่านี้มา โปรแกรมจะคำนวณประมาณการจากราคาของโมเดลและแสดงว่าเป็นค่าประมาณ
- คอลัมน์ "ประมาณ/ครั้ง" ในตารางโมเดลคำนวณจากการใช้งานสมมติ 1 ครั้ง (input 1,000 token, output 1,300 token) ใช้เทียบโมเดลเท่านั้น
- โมเดลที่แสดง $0 อาจคิดราคาด้วยหน่วยอื่นที่ไม่ได้แสดงในรายการราคา

### การเรียก API

- โมเดลที่ออกเป็นรูปและข้อความ ใช้ `POST /api/v1/chat/completions` พร้อม `modalities`
- โมเดลที่ออกเป็นรูปล้วน ใช้ `POST /api/v1/images`
- ถ้า chat/completions ปฏิเสธโมเดลด้วยข้อความที่ชี้ไปยัง `/api/v1/images` โปรแกรมจะลองเรียก endpoint นั้นให้อัตโนมัติ
- รายการโมเดลดึงจาก `GET /api/v1/models?output_modalities=all` เพราะค่าเริ่มต้นของ API คืนเฉพาะโมเดลที่ output เป็นข้อความ

## ที่เก็บข้อมูล

ข้อมูลถูกเก็บไว้ในโฟลเดอร์ต่อไปนี้

| สถานการณ์ | ตำแหน่ง |
| --- | --- |
| รันจากซอร์ส (`.py`) | `UncleImageGenerator_data/` ข้างไฟล์ `uncle_image_generator.py` |
| รันจาก `.exe` (PyInstaller / installer) | `%APPDATA%\UncleImageGenerator\` |

ภายในโฟลเดอร์ข้อมูล:

- `config.json` การตั้งค่าและ API Key (เก็บเป็นข้อความธรรมดา)
- `history.json` ประวัติ prompt, โมเดล, reference และต้นทุน
- `images/` รูปที่สร้างแล้ว

การสำรองข้อมูล: ปิดโปรแกรมแล้วคัดลอกโฟลเดอร์ข้อมูลไปเก็บไว้ที่อื่น

## การ build เป็นไฟล์ .exe

```bash
python -m PyInstaller -i image_gen.ico --noconfirm --clean --windowed --onedir --name UncleImageGenerator uncle_image_generator.py
```

ผลลัพธ์อยู่ในโฟลเดอร์ `dist\UncleImageGenerator\` ตัวโปรแกรมไม่ได้ขอสิทธิ Administrator จึงรันได้ตามปกติ

ตัวติดตั้ง (Setup) สร้างด้วย Inno Setup ผ่าน Installer Builder ใน `build_installer_script/` โดยใช้ค่า Install mode เป็น `lowest` เพื่อติดตั้งต่อผู้ใช้โดยไม่ต้องใช้สิทธิ Admin
